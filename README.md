# Blink-led-STM32-NUCLEO-L432KC-
A simple program to perform the blinking of a LED using the STM32 L432KC, using the IDE from STM.
The Microcontroller was configured using STM32CubeMX v. 6.18.1, and the main.c source code was modified using STM32CubeIDE v. 2.2.0
I provide also the schematic of the circuit and a little video to show the real results.
The main source code is written in C.
